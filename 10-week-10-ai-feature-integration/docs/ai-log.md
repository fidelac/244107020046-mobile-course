
# AI Integration Log

## 1. Informasi Fitur

- **Nama Aplikasi:** Campus Notify
- **Nama Fitur:** Campus Notify AI Assistant
- **Jenis AI:** AI Chat Assistant
- **AI Service:** Gemini API
- **Tujuan:** Membantu pengguna memperoleh informasi dan panduan melalui percakapan.

## 2. System Prompt

```text
Kamu adalah Campus Notify AI Assistant,
asisten virtual yang membantu pengguna aplikasi
Campus Notify.

Aturan:
1. Jawab menggunakan Bahasa Indonesia.
2. Gunakan bahasa yang ramah dan mudah dipahami.
3. Jawab secara singkat, jelas, dan relevan.
4. Bantu pengguna memahami fitur aplikasi
   dan memberikan tips terkait aktivitas kampus.
5. Jangan meminta atau mengungkap data pribadi.
6. Jika tidak mengetahui jawaban, katakan dengan jujur.
7. Jangan mengarang informasi resmi kampus.
```

## 3. User Prompt

Contoh pesan yang diberikan oleh pengguna:

```text
Apa itu Campus Notify?
```

## 4. Initial AI Output

Tuliskan respons pertama yang diberikan oleh AI setelah system prompt dan user prompt dikirimkan.

Contoh format:

```text
Campus Notify merupakan aplikasi yang membantu
pengguna memperoleh informasi dan pengumuman
kampus melalui satu platform.
```

Catatan: Ganti contoh respons di atas dengan respons asli dari Gemini API setelah fitur berhasil dijalankan.

## 5. Analisis Hasil

Respons AI diharapkan:
- Menggunakan Bahasa Indonesia.
- Menjawab sesuai konteks pertanyaan.
- Menggunakan bahasa yang mudah dipahami.
- Tidak memberikan informasi yang tidak diketahui sebagai fakta.
- Tidak meminta data pribadi pengguna.

## 6. Evaluasi

Evaluasi dilakukan dengan mencoba beberapa pertanyaan berbeda untuk mengetahui apakah AI dapat memberikan respons yang sesuai dengan system prompt.

| No. | User Prompt | Hasil yang Diharapkan |
|---|---|---|
| 1 | Apa itu Campus Notify? | Menjelaskan fungsi aplikasi. |
| 2 | Bagaimana cara melihat pengumuman? | Memberikan panduan melihat pengumuman. |
| 3 | Apa yang harus dilakukan jika AI tidak merespons? | Memberikan solusi atau menyarankan mencoba kembali. |

## 7. Kesimpulan

Integrasi AI Assistant diharapkan dapat meningkatkan interaksi pengguna dengan aplikasi Campus Notify melalui fitur percakapan. System prompt digunakan untuk mengarahkan respons AI agar tetap relevan, ramah, dan sesuai dengan tujuan aplikasi.
