## Refleksi
#### 1. Kapan native lebih tepat dipilih daripada cross-platform?
- Native lebih tepat dipilih ketika aplikasi membutuhkan akses yang sangat spesifik terhadap fitur atau kemampuan perangkat tertentu, serta membutuhkan performa yang optimal.

#### 2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?
- State merupakan kondisi atau data yang dapat berubah dalam aplikasi. Ketika state berubah, tampilan pada widget yang berkaitan juga dapat berubah. Flutter menggunakan widget tree untuk membentuk tampilan aplikasi dan konsep UI deklaratif untuk menentukan tampilan berdasarkan state saat ini.

#### 3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?
- Commit kecil dengan pesan yang jelas membuat perubahan dalam project lebih mudah dilacak dan dipahami. anggota tim dapat mengetahui perubahan apa yang dilakukan tanpa harus memeriksa seluruh kode.
- Untuk portfolio, riwayat commit yang rapi dan jelas juga dapat menunjukkan proses pengembangan project.
